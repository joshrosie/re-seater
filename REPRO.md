# 🔁 Reproducibility Instructions

This document provides the full set of instructions to reproduce our project results from scratch, including data setup, environment configuration, training, and evaluation.

---

## 🧱 Project Structure

```bash

├── SEATER_Generative_Retrieval/   # Root directory for all project source code.
    ├── config/                    # Contains all configuration files (.yaml) for different datasets .
    ├── data/                      # Stores the datasets used for training and evaluation.
    ├── data_bert4rec/             # Stores data preprocessed in the specific format for BERT4Rec.
    ├── model/                     # Implementations of SEATER and all baseline models.
    ├── utils/                     # Helper functions for data loading, logging, etc.
    ├── trainer.py                 # Handles the core training, validation, and testing loops.
    ├── main.py                    # Main entry point to run the experiments.
    ├── calculate_metrics.py       # Standalone script to compute metrics from saved checkpoints.
├── requirements.txt        # Python dependencies
├── README.md               # README file
├── REPRO.md                # This file
├── jobs/                   # Slurm files for snellius
```

## ⚙️ Environment Setup

To setup the seater environment, run the ```install_environment.job``` which is located inside the ```jobs/``` directory.

## 📂 Download & Prepare Datasets

### Books

For the Books dataset, download the reviews from the Amazon 2018 version from the following link https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/and place the ```Books_5.json, meta_Books.json``` files inside ```SEATER_Generative_Retrieval/data/Books/raw_data``` directory. 

Then, run the ```create_txt_splits_final.py``` to create the train/validation/test splits inside the ```SEATER_Generative_Retrieval/data/Books/data/book_data``` directory. Then, run the ```SEATER_Generative_Retrieval/data/Books/preprocess_final.ipynb``` file to create the training, validation and test tsv files inside the ```SEATER_Generative_Retrieval/data/Books/dataset``` directory. 

Also, make sure you run the ```SEATER_Generative_Retrieval/data/Books/map_to_categories.ipynb``` to create the mapping of items to categories which is essential for the calculation of the fairness/diversity metrics. 


### Yelp

For the Yelp dataset, download the preprocessed version the authors of SEATER suggested from the LightGCN repo using the following link https://github.com/kuandeng/LightGCN/tree/master. From the Data/yelp2018 folder download the following files item_list.txt, test.txt, train.txt, user_list.txt and place them inside ```SEATER_Generative_Retrieval/data/Yelp/LightGCN```. 

Then, run the ```SEATER_Generative_Retrieval/data/Yelp/preprocess_from_authors.ipynb``` to get the training/validation/testing tsv files. To create the mapping of items to categories which is essential for the calculation of the fairness/diversity metrics, make sure you download the Yelp 2018 dataset from https://recbole.io/dataset_list.html. Then place the ```yelp_academic_dataset_business.json``` file in the  following directory ```SEATER_Generative_Retrieval/data/Yelp/Yelp_JSON_2018```. Then, run the ```SEATER_Generative_Retrieval/data/Yelp/map_to_categories.ipynb``` to get the ```id2cat.json``` file inside the ```data/Yelp/dataset``` directory. 

### News

For the News dataset, we utilize the MIND-small training set from https://msnews.github.io. Download the training set and place the downloaded ```MINDsmall_train``` under ```SEATER_Generative_Retrieval/data/Mind/MINDsmall_train```. 

To generate the preprocessed data for training and evaluating SEATER, SASRec and GRU4Rec, run ```SEATER_Generative_Retrieval/data/Mind/preprocess.ipynb```. The preprocessed data for BERT4Rec can be generated by running ```SEATER_Generative_Retrieval/data/Mind/preprocess_bert4rec.ipynb```.

 Also, make sure you run the ```map_to_categories.ipynb``` to create the mapping of items to categories which is essential for the calculation of the fairness/diversity metrics  to get the ```id2cat.json``` file inside the ```data/MIND/dataset``` directory. 

### Yambda

The Yambda-5B dataset can be downloaded from https://huggingface.co/datasets/yandex/yambda. For our experiements we utilize the sequential 50M version: https://huggingface.co/datasets/yandex/yambda/tree/main/sequential/50m. Download the files from https://huggingface.co/datasets/yandex/yambda/tree/main/sequential/50m and place them within a directory: ```SEATER_Generative_Retrieval/data/Yambda/50m```. 

To generate the preprocessed data for training and evaluating SEATER, SASRec and GRU4Rec, run ```SEATER_Generative_Retrieval/data/Yambda/preprocess.ipynb```. This file also creates the mapping of items to categories which is essential for the calculation of the fairness/diversity metrics to get the ```id2cat.json``` file inside the ```data/Yambda/dataset``` directory. 
To generate the preprocessed data for training and evaluating BERT4Rec run ```SEATER_Generative_Retrieval/data/Yambda/preprocess_bert4rec.ipynb```. 





## 🚀 Training experiments

For training the baselines, select one of the following commands:

- SASREC: ```jobs\experiment_SASREC.job```
- GRU4REC: ```jobs\experiment_GRU4REC.job```
- BERT4REC: ```jobs\experiment_BERT4REC.job```

To train SEATER, you must first train SASREC on the corresponding dataset and then extract its item embedding layer using the ```extract_embeddings.ipynb``` notebook which is located in the ```SEATER_Generative_Retrieval/data/{dataset_name}``` directory, where ```dataset_name = {Books, Yelp, MIND, Yambda}```. 

In the notebook, make sure to provide the path to the best SASREC checkpoint.
Once the embeddings are extracted, you can proceed to train SEATER for all datasets by running the following job:

- SEATER: ```jobs\experiment_SEATER.job```

For the speedup experiments on the SEATER model, run the following commands:

- Speedup: ```jobs\experiment_seater_speedup.job```
- Hybrid: ```jobs\experiment_seater_hybrid.job```

For the normalization experiments on the SEATER model, run the following commands:
- Diversity: ```jobs\experiment_normalization_diversity.job```
- Accuracy: ```jobs\experiment_normalization_accuracy.job```

## 📈 Evaluating Fairness/Diversity Aspects

Below is a sample usage of the calculate_metrics.py script to compute the full set of metrics, including fairness and diversity metrics, by providing the checkpoint path to the best saved model.

### Run SEATER model on Books dataset 
```python calculate_metrics.py  --name SEATER_Books --dataset_name Books  --num_workers 16 --gpu_id 0 --model SEATER  --vocab 16  --epochs 60  --test_batch_size 512  --wandb_project fairness  --ckpt_path /your/directory/to_the_best_model/ckpt.pth ```

### Run SASREC model on Books dataset 
```python calculate_metrics.py  --name SASREC_Books  --dataset_name Books  --num_workers 16  --gpu_id 0  --model SASREC  --vocab 16  --epochs 60  --wandb_project fairness --ckpt_path /your/directory/to_the_best_model/ckpt.pth``` 

### Run BERT4REC model on Books dataset 
```python calculate_metrics.py  --name BERT4REC_Books --dataset_name Books  --num_workers 16 --gpu_id 0 --model BERT4REC  --wandb_project fairness --ckpt_path /your/directory/to_the_best_model/ckpt.pth``` 

### Run GRU4REC model on Books dataset 
```python calculate_metrics.py --name GRU4REC_BOOKS --dataset_name Books  --num_workers 16 --gpu_id 0 --model GRU4REC --wandb_project fairness --ckpt_path /your/directory/to_the_best_model/ckpt.pth ```
